# 角色详情页改版

## Goal

按设计稿（`research/design-reference.jpg`）重做 `RoleCreatePage`（新建 / 编辑共用）的视觉与信息层级：
立绘头图下方出现纸面「身份头」（大头像、名字、标签、一句设定、导出角色卡），
表单改为「图标标题分区卡 + 双列字段格」。全部沿用现有 崽档 Token 体系，
不引入新色相、新字体、新依赖，不改变任何数据契约与保存 / busy 逻辑。

## Requirements

### 已确认取舍

1. 字段格子本身就是输入框（inline 编辑）；顶部「保存」统一提交。表单校验、
   `_saving` / `_tabBusy` 门禁、`PopScope`、世界观选择器、自定义属性拖拽排序、
   修改历史恢复等现有行为全部保留。
2. 严格沿用 Token：标签用纸底细描边（`bg` 填充 + `border` + `micro` ink），
   装饰只保留火漆红星芒（`Icons.auto_awesome`）与引号图标；不做英文手写字、
   彩色标签、爪印 / 爱心。
3. 新卡片样式同时用于新建页与编辑页；身份头在两种模式都出现：新建时头像为
   「添加立绘」占位、名字回退为 `新建角色`；编辑时名字回退为 `未命名角色`。
4. 自定义属性区换成同款卡头，位置仍在「基础设定」与「角色简介」之间，机制不变。
5. 世界观编辑页不传新槽位即维持原样；共享的保存按钮改为 accent 实心药丸，
   两个编辑页一并继承。

### 身份头

- 位于头图之下、Tab 之上，属于 pinned `SliverAppBar` 的 flexibleSpace 纸面区域；
  滚动时随头图一起被 Tab 压过，吸顶后仍由 `PinnedIdentity` 提供识别信息。
- 头像：圆角方、`surface` 描边 + 柔和阴影，上半部分压在立绘上；沿用
  `Key('role-create-cover-portrait')`。有图点开预览（语义 `查看立绘`），角标
  按钮 `Key('role-cover-change')` 语义 `更换立绘`；无图占位文案 `添加立绘`，
  点击选图。保存中 / busy 时预览与更换不可用。
- 名字 `title` + accent 星芒；标签为非空的 种族 / 身份 / 性别；引文为 设定 的
  首行套 `「」`，最多两行，空则不占位；右侧 `导出角色卡`（`Key('role-card-export')`）。
- 名字 / 性别 / 种族 / 身份 / 设定 输入时身份头实时刷新，且只重建头部。

### 详情表单

- 「基础设定」卡：卡头 = accent 淡底图标 + 标题 + 右侧 `caption` 说明。字段按
  （名字 | 性别）（年龄 | 生日）（种族 | 身份）双列排布，世界观整行带右箭头
  （`Key('role-world-row')` 与弹层行为不变）。每个字段 `Key('role-field-<name>')`。
- 字段格：`bg` 填充 `smAll` 圆角，顶行 accent 小图标 + `micro` 标签，下方为
  无边框输入；聚焦描边 accent，校验错误描边 ink 并显示错误文案 `请填写名字`。
- 「角色简介」卡：卡头 + 输入框外套 `surface + border` 盒并叠低透明 accent
  引号装饰（排除语义）；`修改历史` 为盒下右对齐文字按钮（仅编辑）。
- 「自定义属性」卡：仅卡头替换，行内交互与键不变。
- Tab：`详情 / 资产 / 关系` 保持 `Key('role-detail-tabs')`，选中 accent 下划线，
  外层仍为 `bg` 不透明底以遮住滚动内容。

### 约束

- 不写 `fontSize` / `fontWeight` / 数字 `EdgeInsets` / 数字间隙 `SizedBox` /
  `Radius.circular`；新增尺寸一律命名常量（`design_token_guard_test`）。
- 共享组件放 `lib/widgets/archive_editor/`，数据进回调出，不读 provider。
- 文案中文、`…`、`「」`；卡头说明控制在一句短语，不用「他 / 她」与英文。

## Acceptance Criteria

- [ ] 新建页：显示 `新建角色` 回退名、`添加立绘` 占位、`基础设定` / `角色简介`
      卡头、双列字段格；空名保存出现 `请填写名字`；填写后保存成功并返回列表。
- [ ] 编辑页：身份头显示名字、标签（种族 / 身份 / 性别）、`「设定首行」`、
      `导出角色卡`；三个 Tab 正常切换，草稿与滚动位置保留。
- [ ] 输入名字 / 性别 / 种族 / 身份 / 设定 后身份头即时刷新。
- [ ] 有立绘：点头像进预览，角标语义 `更换立绘`；无立绘：`添加立绘` 点击选图。
      保存中两者均禁用，且不会在保存完成时弹掉预览。
- [ ] 世界观整行与弹层行为、自定义属性拖拽 / 上下移 / 删除、修改历史恢复行为不变。
- [ ] 吸顶后 `PinnedIdentity` 出现，Tab 栏底不透明，像素回归测试通过。
- [ ] 世界观编辑页除保存按钮配色外无变化，其测试全部通过。
- [ ] `flutter analyze` 无问题、`flutter test` 全绿、`dart format .` 无 diff。
- [ ] `.trellis/spec/frontend/` 中 `role-assets.md`、`worlds.md`、
      `component-guidelines.md`、`theming.md` 已同步新组件签名与契约。
