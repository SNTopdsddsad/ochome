# 角色编辑页可预览立绘大图

## Goal

在新建 / 编辑角色页能点开立绘看原图。换图必须走单独入口，避免点模糊背景或点头像就打开相册。

2026-09-05 用户追加：采用成熟第三方图库，预览页支持图片列表、指定初始图片、左右切换、双指缩放和单击退出。该追加取代原先「不引入第三方看图库」的限制。角色当前单张立绘作为单元素列表进入预览；本次不增加角色多图存储或多选上传。

## Background

`RoleCreatePage`（`lib/pages/role_create_page.dart`）新建和编辑共用。每个角色只有一张本地立绘 `Role.coverImg`：顶部全宽 352pt 头图是同一张图的高斯模糊背景，左下角名片是清晰 3:4 小立绘（`CoverFileView`，`BoxFit.cover`）。

当前点击（上一任务 `09-01-role-create-page-style` R2 / AC2）：

- 点模糊背景 → `_pickCover()` 打开相册（`_ImmersiveCover` 的 `GestureDetector.onTap: onPick`，约 L499–503）
- 点整张名片（立绘 + 名字）→ 同样 `_pickCover()`（`_CallingCard` 的 `InkWell.onTap: onPick`，约 L581–583）
- 无图时小立绘槽文案是「添加立绘」

仓库没有全屏看图页。列表页点整行仍进编辑页，本次不改。选图仍走 `CoverImagePicker.pickFromGallery()`。

## Requirements

- **R1** 已有可读立绘时，点左下角清晰立绘（3:4 槽，不含名字、不含更换按钮）打开全屏原图预览：`BoxFit.contain`，不模糊、不按 3:4 裁切。支持捏合缩放。点关闭或系统返回只退出预览，不改 `coverImg`，不 pop 编辑页、不提交表单。立绘槽无障碍标签为「查看立绘」。
- **R2** 有立绘时，名片上另有独立控件，文案「更换」，无障碍标签「更换立绘」。只有点它才打开相册。取消选择则画面不变。该控件不叠在 3:4 立绘槽上，避免抢走预览点击。
- **R3** 无立绘，或立绘路径对应文件不存在时：3:4 槽仍显示「添加立绘」，点它打开相册；不出现「更换」，不进入全屏预览。
- **R4** 有立绘时，点模糊背景、点名片上的名字 / 种族·身份文字，都不打开相册、不进预览。
- **R5** 不新增封面字段，不改选图落盘，不把背景和头像拆成两张图。列表页入口和 56 方形缩略图不变。字段、保存、校验、设定历史不变。
- **R6** 预览层和「更换」控件颜色走 `ZaidangTokens` / `Theme.of(context)`。火漆红不铺满预览底。
- **R7** 预览页接受本地图片路径列表与初始索引，使用 `photo_view` 的成熟手势与画廊组件，左右滑动切图，每张图片支持双指缩放、拖动和双击缩放，初始完整展示原图。
- **R8** 单击图片或背景、点击关闭按钮、系统返回均只关闭预览层；缩放、双击和左右滑动不得误触退出。多图时显示当前张数 / 总数，单图不显示页码。
- **R9** 延续相对路径 `covers/<file>` 和绝对路径两种输入。列表中的缺失或损坏图片显示可理解的失败状态，仍能退出或切到其他图片；空列表可正常退出。

## Acceptance Criteria

- [ ] **AC1** 编辑已有可读立绘的角色：点左下角清晰立绘进入全屏预览，能看到未被模糊、未被 3:4 裁切的原图；关闭或系统返回后仍在编辑页，立绘路径不变。
- [ ] **AC2** 有立绘时点模糊背景、点名片名字区域不打开相册、不进预览。点「更换」才打开相册；取消选择后面面不变。
- [ ] **AC3** 新建页无立绘：点立绘槽仍是「添加立绘」并打开相册；没有「更换」。选图成功后，再点立绘是预览而不是立刻再打开相册，同时出现「更换」。
- [ ] **AC4** 全屏预览支持系统返回和明确关闭控件。预览不提交表单、不 pop 掉编辑页。
- [ ] **AC5** 立绘路径非空但文件缺失时，表现与无立绘一致：槽显示「添加立绘」，点它选图，不进空白预览页。
- [ ] **AC6** 现有创建 / 编辑保存、名字必填、设定历史、列表入口行为保持不变。`test/widget_test.dart` 相关用例仍通过，并覆盖「有图点立绘预览 / 点更换才选图 / 空态添加立绘 / 点背景不选图」。
- [ ] **AC7** 传入至少 3 张图，能从指定索引打开并左右切换，页码与当前图片同步；每张可双指 / 双击缩放，手势不会误关预览。
- [ ] **AC8** 单击、关闭按钮和系统返回只退出预览；单图入口、保存中的预览禁用及关闭按钮对比度回归通过。
- [ ] **AC9** 缺失图片显示失败状态并可继续切图，空列表可正常关闭；初始索引越界时安全限制在有效范围。

## Out of Scope

- 角色列表页点缩略图看大图
- 第二张封面 / banner 字段，或相册裁切独立横幅
- 改 `CoverImagePicker` 落盘路径或压缩策略
- 改字段、保存、校验、设定历史
- 角色多图存储、相册多选和新增图集管理入口
- 预览页分享、保存到相册、删除立绘

## Risks

- 现有测试把「点 hero / 点名片」当成选图入口。改交互后必须改测试，否则会把预览误判成选图失败。
- 全屏预览若用 `Navigator.push` 且没挡住手势，返回栈容易和编辑页 pop 搞混。关闭预览必须只 pop 预览层。
- 名片宽度有限。 「更换」必须在立绘槽外，否则 R1 和 R2 的点击会打架。
